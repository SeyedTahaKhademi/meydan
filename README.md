# هم‌میدان ۵ — Kotlin Native

رابط بومی Android Views، بدون WebView، با سه فایل Kotlin: MainActivity، Api و CityMap.
سرور ثابت: https://hooyar-si.ir/meydooon/api.php
بک‌اند سازگار: بسته PHP/JSON نسخه ۴؛ در public_html/meydooon استخراج شود. PHP 8.1+، GD برای تصاویر، cURL برای همیار. کلید هوش مصنوعی فقط سمت سرور؛ مسیر گفتگو و نام مدل باید تنظیم شوند.

## ساخت APK
- پوشه پروژه را در ریشه مخزن GitHub قرار دهید (پوشه مخفی .github را هم منتقل کنید).
- در Actions گردش‌کار Build HamMeydan Kotlin APK را اجرا کنید.
- پس از موفقیت، Artifacts / HamMeydan-v5-kotlin را دانلود کنید.
- گردش‌کار Gradle 8.9، JDK 17، Android SDK 35 و Kotlin 2.0.21 را استفاده می‌کند و فونت وزیرمتن را پیش از build از منبع رسمی دریافت و داخل APK بسته‌بندی می‌کند.
- در Android Studio هم بعد از Gradle sync و دریافت فونت (مطابق workflow) می‌توانید Build APK(s) را اجرا کنید.

## وضعیت
- بررسی نحوی هر سه فایل Kotlin با parser رسمی Kotlin 1.9 انجام شد. بدون Android SDK بررسی کامل نوع‌ها و build، نصب و آزمون UI امکان‌پذیر نبود.
- تصویر لوگو، تصویر placeholder، آرشیو منبع‌دار و نقشه کلی ایران در منابع محلی برنامه قرار دارند. فونت هنگام build دریافت می‌شود؛ تا آن زمان از فونت سیستم استفاده می‌شود.
- داده‌های عمومی cache می‌شوند؛ تصاویر کاربران آنلاین هستند؛ پیام‌ها با تازه‌سازی دستی به‌روزرسانی می‌شوند.
- این نسخه نقشه کلی شهرها و اطلاعیه‌های عمومی منبع‌دار دارد، نه نقشه لحظه‌ای اشخاص.
- بک‌اند نسخه ۴ بدون تغییر استفاده می‌شود؛ از داده‌های JSON خصوصی فعلی نسخه پشتیبان بگیرید و config.php فعلی را بدون بررسی بازنویسی نکنید.
- ورود مهمان بعد از خروج یا انقضای نشست قابل بازیابی نیست.
